## Slides 45–47 — Core lab

### Create

> Using the three source sections in this document, write exactly five sentences: 1. Overall status. 2. Timeline confidence. 3. Single top risk. 4. Business impact if that risk occurs. 5. Recommended next action. Use only facts in this document.

### Refine

> Polish this status update for executive readability. Keep exactly five sentences in the same order. Make each sentence concise and specific. Preserve every name, number, date, and fact. Make the top risk and recommended next action unmistakable. Do not add new information.

### Verify and fix

> Audit every claim in this five-sentence update against the three source sections. For each claim, give the source evidence, status (Supported, Partly Supported, Unsupported, or Recommendation/Judgment), and correction needed. Check dates, numbers, status, timeline confidence, risk, impact, and cause-and-effect statements. Then return a corrected five-sentence update using only supported facts. Label recommendations clearly. If a source does not answer something, say so. Do not infer or invent.
